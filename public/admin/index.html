💡 Como conectar mas pantallas

Para conectar una nueva computadora o pantalla como cliente kiosko, usa esta URL:

1 En la otra computadora, abre un navegador (Chrome/Chromium)
2 Pega la URL de arriba (reemplaza "nombre" por el nombre de la pantalla)
3 Opcional: usa el script scripts/start-kiosko.sh en Linux para modo kiosko automatico
4 La pantalla aparecera en este panel automaticamente
